SageMath 安装

2025-10-08 00:00 · Tech

安装

1.archlinx或者voidlinux使用自身的包管理器可以安装最新版本

2.其他发行版本（如：ubuntu）使用conda安装（参考：Install from conda-forge）：

（1）下载并安装miniforge：（miniconda、anaconda等，国内可以使用清华源下载安装文件）

curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh

（2）下载sagemath环境

conda config --add channels conda-forge
conda config --set channel_priority strict
conda create -n sage sage python=3.12

（3）激活使用sage环境

conda activate sage

3.ubuntu包管理器中的sagemath和windows平台的sagemath版本比较久，不建议使用。

提醒 ：VScode上的sagemath Enhanced插件的新版本存在问题，建议从github上找v2.0.1(如果觉得会显示更新提醒信息，就把packages.json里的name和作者随便改一下，并用此源码再编译一个
